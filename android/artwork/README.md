# Link to Linux Android icon

`link-to-linux-icon.png` is the original generated artwork. The launcher uses
`../app/src/main/res/drawable-nodpi/ic_launcher_artwork.png`, resized to 432 × 432,
with the adaptive icon definition in `mipmap-anydpi-v26/ic_launcher.xml`.

Generated using the built-in image generation tool with this prompt:

Create a polished, simple flat emblem: two bold interlocking rounded chain links, one shaped subtly like a smartphone outline and one like a computer display, forming a cohesive diagonal link symbol. Match the app palette: ice blue #7DD3FC and white on solid near-black #050505. Square 1024x1024 full bleed near-black background, no rounded outer tile, no text, no letters, no watermark, no mockup, no shadows. Keep the entire emblem centered inside the middle 60 percent of the canvas with generous empty margins so Android circle and squircle masks do not clip it. Crisp geometry, strong silhouette readable at 48 pixels.
